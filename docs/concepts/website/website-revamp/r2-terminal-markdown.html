## How one skill works

Take decisions-logger. You've just decided something — "plain CSS Modules, not Tailwind."

  1. 1.It reads the evidence git log, the config that changed, the PR thread. Not your memory.
  2. 2.It asks what it can't find "why did Tailwind lose?" — and every question offers "I don't remember."
  3. 3.It writes the record docs/decisions/0018-…md — with the option that lost named, or it isn't a decision.
  4. 4.It registers the rule a block in CLAUDE.md, the file your agent re-reads every session.
  5. 5.Next session, unasked it offers to log the next one. You never have to remember the habit.

Step 4 is the one nothing else does. A skill that stopped at step 3 would be forgotten by tomorrow — you'd have one good document and no second one. The rule is what makes it happen again.

> Seven rules live in this repo's CLAUDE.md. They have produced 23 decisions, 6 design decisions, 31 documented commits and 3 handoffs — [all of it readable].

## The skills

Fourteen, each a separate plugin. Three worth reading properly; the rest are one line each.

decisions-logger Code · Chat
Why did we choose that?

Mines the project for decisions that were really made and writes each as a numbered ADR with its evidence. Where the reasoning was never written down it asks — and if nobody remembers, writes *(reason not stated)* rather than a plausible sentence.

```sh
/plugin install decisions-logger
```
exploration-log Code · Chat
Did we already try that?

Logs a round of iteration — what it tested, what changed, what you learned, and whether it was kept, killed or parked, with the reason. Append-only, so a direction you abandoned is still readable a year later. Answers the question back, too.

```sh
/plugin install exploration-log
```
changelog-tracker Code · Chat
What actually shipped?

Documents every substantive commit into a per-commit file plus a rolling index. Every fact comes from `git log` — faithful, not generative. Needs git, so Claude Code only.

```sh
/plugin install changelog-tracker
```

## Install

Read a couple of the records above before you trust it with your repo — including the one that says it doesn't know.

```sh
# once
/plugin marketplace add vidhunnan/agentic-skills

# start here — it builds the folders the rest fill
/plugin install repo-setup
/repo-setup

# then add the rest as you hit the need for them
```

Claude Code gives you the system. Claude.ai gives you the artifact. On Claude.ai a skill interviews you and hands back a document — no folder to write into, and no rule registered, so nothing happens next session unless you paste the block yourself. Skills marked Chat above have that path; the rest need git.
