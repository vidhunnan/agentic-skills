Six skills, all live

An agent starts every session with no memory of the last one.

It doesn't need a better prompt — it needs a briefing. These skills author the context files a project should have anyway: a changelog of what shipped, a decision log of why, a handoff for where you left off. All markdown. No build system, no application code.

The context stack

Five tiers, one rule

Every folder answers one question a teammate would ask — and declares exactly how far an agent should trust what's inside it. Click a tier to see what actually lives there. Mix the tiers and you've handed an agent contradictory instructions; a human pushes back, an agent just agrees.

The skills

Set up the repo

repo-setupCODE · CHAT

Scaffolds the context stack. Surveys what you already have, adopts your existing folder names, and never moves or overwrites a thing.

/plugin install repo-setup
$ /repo-setup
✓ docs/concepts/   (new)
✓ docs/prds/       (existing, adopted)
✓ docs/decisions/  (new)
✓ handoff/         (existing, adopted)
✓ changelog/       (new)

Keep the record

changelog-trackerCODE

What actually shipped? Documents every substantive commit — a per-commit file plus a rolling index, sourced entirely from git.

/plugin install changelog-tracker

decisions-loggerCODE · CHAT

Why did we choose that? Mines real decisions and writes each as an ADR with its evidence. Where the reasoning was never written down, it asks — it never invents one.

handoff-generatorCODE · CHAT

Where did we leave off? An interactive, bidirectional Chat↔Code handoff: progress, decisions, changelog delta, open questions, next actions, and a near-verbatim session log.

Working conventions

branch-namingCODE

Proposes a branch name that fits your project's convention — read from CLAUDE.md, or inferred from your existing branches. Always confirms before creating.

/plugin install branch-naming
$ /branch-naming "add filter chips"
→ feat/skills-filter-chips
  branches off prod-stable — confirm? (y/n)

Everything above was used to build this repo, so you can read the output before you trust it with yours.

Get started

Install

Add the marketplace once. Then install the skills you want — each one is a separate plugin.

$ /plugin marketplace add vidhunnan/agentic-skills
 
# then, any combination of —
$ /plugin install repo-setup
$ /plugin install changelog-tracker
$ /plugin install decisions-logger
$ /plugin install handoff-generator
$ /plugin install branch-naming
$ /plugin install model-strategy
Claude.ai — zip a skill folder and upload it under Settings → Customize → Skills. Skills marked Chat above have a claude.ai path; the rest need a filesystem and git.
