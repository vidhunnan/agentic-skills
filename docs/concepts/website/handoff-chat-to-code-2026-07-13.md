## Context

A ~10-minute talk deck, **"Writing for Machines: The Non-Coder's Context Stack"**, was
built and finished in this chat session for a Claude/AI community event in Bangalore
(theme: memory, context & agents). It is a single self-contained HTML deck, 33 slides,
now at **v7**, shipped in three builds (annotated, presentation, PDF). The deck's thesis
is that an agent is "a teammate with amnesia" and that the speaker's lever is
communication, not code — every context artifact is markdown, none of it is code.

The next work moves to **Claude Code**, and the receiver should pick up the
**skills repo** (`vidhunnan/agentic-skills`) — the repo intended to host personal
Claude/Cursor skills. The `handoff-generator` skill was the first planned skill for that
repo and was invoked at the end of this session to produce this very brief.

## Decisions Made

### Deck — settled

- **Deck is at v7, 33 slides, all figure plates filled with real screenshots** — zero placeholders remain.
- **Three build artifacts, not one** — annotated (speaker notes, `N` toggles), presentation (notes stripped, full-bleed, 112px side padding), and PDF (33 pages, no nav chrome). — the presentation and PDF builds are regenerated from the annotated build, which is the source of truth.
- **Histogram rebuilt as animated SVG** — CSS percentage-height bars inside a shrink-to-fit flex item resolved to zero and rendered blank; SVG `scaleY` with `transform-box: fill-box` does not have that failure mode.
- **Dual-series histogram (commits + lines of code)** — chosen over a single series because the divergence *is* the point: Jun 13 was the peak commit day (42), Jun 10 was the peak code day (+37,490 lines).
- **Case study is four slides** (cover breather, numbers bento, phase-system bento, the seam) — added after the handoff slides, because the case study proves the system rather than merely describing it.
- **Failure beat moved to slides 12–13**, before the reframe — so "an agent is a teammate with amnesia" arrives as a conclusion rather than an assertion.
- **Case-study closing line is "I wrote the context."** — "I wrote the prompts" was rejected because the deck spends thirty slides arguing against prompting; "I wrote the documents" was rejected as inaccurate (claude.md and the changelog are generated, not typed).
- **claude.md is described as generated, not hand-written** — the user reads it and keeps it honest; he does not type it.
- **Slide 8 uses "a readme file", not "an npm package"** — a README is literally a markdown file written for an absent reader, so the parallel to a context file is exact.
- **Timeframe is "the last couple of years", not "seven years"** (slides 8 and 9) — user's correction; the smaller number is the one he'd defend.
- **Slide 15 headline is "I only changed the reader."** — the attribution slide's observation, paired with slide 8's "I didn't know what for."
- **Slide 21 model claim reads: "assigned in the plan, confirmed in the picker — my call."** — reconciles the plan's four-model tiering with the git trailers, which are all Opus. The user selects the model in the Claude Code picker; the plan proposes.
- **Slide 29 headline is "Don't say it twice. Write it down."** — replaces "Don't prompt louder. Re-brief it."
- **Colophon closes on "This deck was generated by Claude. Authored by me."** — typeface credits removed.

- **Slide 21 — the model-tiering claim.** The user's own audit (`claude-usage-review__1_.md`) found that every git co-author trailer in the reviz history names **Opus**; no Sonnet, Haiku, or Fable trailer exists, so the four-tier plan never executed. Do not treat as closed.

- **Slide 32 contact handles** — `github.com/vidhunnan` and `@vidhunnan` are on the Q&A slide and have not been verified.
- **Slide 20 doc-types table** — the user said the folder names are "evolution based on various repos." Two rows (`creation-log/`, `docs/decisions`) were originally assistant inferences and were never individually confirmed against a specific repo.
- **Full-bleed crop on non-16:9 screens.** The presentation build scales to *cover*. On a 16:10 laptop this crops roughly 80px per side; side padding was raised to 112px to compensate, but this has not been verified on the actual presentation hardware.
- **Skills repo scope** — beyond `handoff-generator`, which skills go in `agentic-skills` first, and what the repo structure should be, has not been decided.
