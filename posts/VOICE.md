# Voice

**Status: NOT CAPTURED.** Only the banned half of this file is real.

The positive half needs an interview plus three to five posts actually written by
the author. It has neither, so it has been left empty rather than filled with a
plausible voice nobody chose. Any draft produced against this file is generic by
construction and should be read as a structural test, not as finished copy.

## Banned moves

Hard-coded, before any captured voice applies.

- **No em dashes.** A full stop or a comma does the job.
- No "excited to announce", "thrilled to share", "so proud to".
- No emoji bullets. No hashtag stacks.
- No rhetorical-question openers. *"Ever wondered why…?"*
- No "here's what I learned:" listicle scaffolding.
- No invented metrics. A number appears only if a source contains it.
- No manufactured struggle arc.
- None of: game-changer, unlock, leverage, dive deep, supercharge, seamless.
