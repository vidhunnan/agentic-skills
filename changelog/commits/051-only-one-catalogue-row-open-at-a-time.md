# feat(website): only one catalogue row open at a time

## Commit message

Native exclusive accordion — the `name` attribute on <details> — rather than
controlled open/close state.

It costs nothing: no state, no effect, no re-render, and it keeps working with JS
off, which a controlled version would not. This page's standing rule is that JS may
enhance but never reveal, and a JS-driven accordion would have put the whole
catalogue behind a script.

Browsers without support (Chrome <120, Safari <17.2, Firefox <130) fall back to
allowing several open at once — which is exactly the behaviour that shipped until
now, so the degradation is the old design rather than a broken one.

Guarded by a test, and the guard was checked by removing the attribute and watching
it fail: everything still opens without it, just all at once, so the regression
would otherwise be silent.

28 tests passing.
