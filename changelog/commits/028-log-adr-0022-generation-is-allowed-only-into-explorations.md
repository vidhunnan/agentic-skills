# docs(decisions): log ADR 0022 — generation is allowed, but only into explorations

## Commit message

ADR 0021 restricted every design skill to interview/record/structure/check and
forbade generating a visual or proposing a direction. `design-explore`, built
outside the library against a real project, does both — its own PRD said so and
said adoption would require returning to that decision.

0022 narrows 0021 rather than reversing it. Generation is permitted into
`design/explorations/` only, under three conditions that all must hold: a written
visual intent exists first, the artifacts are candidates and never the record, and
the verdict belongs to `exploration-log` / `design-decisions`. The four record
tiers stay under 0021 unchanged.

0021's body is untouched — the only change to it is a dated Follow-up entry, which
is what append-only permits. Its Status stays Accepted: the scope changed, the
decision did not.
