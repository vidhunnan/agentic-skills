## Commit message

Generates a new skill in this library's conventions from a short interview:
the PRD, the SKILL.md skeleton, plugin.json, the marketplace entry, the
README row and install line, and the website's SKILL_GROUPS entry.

Two rules it is built around:

- Scaffold, never generate. It writes headings, frontmatter and
  registrations, not the Steps. A scaffold that invents behaviour produces
  a plausible skill that does nothing, which is worse than an obvious stub.
- The description is the product. It is the auto-invocation matcher, so
  trigger phrases are interviewed rather than invented and the assembled
  description is shown back before use. A description that matches nothing
  fails silently.

Documents seven touchpoints. CONTRIBUTING.md listed six -- it omitted
website/components/lib/skills.ts, so adding a skill by hand left the
published site stale.
